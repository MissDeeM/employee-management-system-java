# Employee Management System

A small Java project I built while practising Java, OOP and SQL.

The idea was to make a simple employee management system where a user can add employees, view them, search for an employee, update details and delete employees.

I wanted to practise working with a database because I was trying to understand how information moves between an application and a database.

## Features

- Add an employee
- View all employees
- Search by employee name
- Update employee details
- Delete an employee
- Store employee information in MySQL

## Technologies

- Java
- MySQL
- JDBC
- Object-Oriented Programming

## What I learned

While working on this project I practised:

- Creating Java classes and objects
- Using methods
- Taking input from the user
- Writing SQL queries
- Connecting Java to MySQL with JDBC
- Using prepared statements
- Handling simple errors
- Updating and deleting records

## What I would improve

If I continue working on this project, I would like to add a graphical interface, better input validation and a login system.

## Note

This is a learning project and is still a work in progress.
